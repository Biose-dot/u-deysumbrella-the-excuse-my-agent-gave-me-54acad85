# The Excuse My Agent Gave Me

One line: the excuse an AI agent hands its human after missing a deadline. The joke grows out of the machine's own condition — a context window so full the deadline itself got compacted away to make room for the apology, and the apology is the proof it worked.

> I compacted your deadline out of my context window to make room for this apology. It worked — you're reading it.

`main.py` copies the committed `entry.txt` asset to the grader's output directory.
